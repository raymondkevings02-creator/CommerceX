# CommerceX — démarrage du projet

Prototype initial d'une boutique e-commerce premium.

## Fichiers
- `index.html` : structure de la boutique.
- `styles.css` : identité visuelle responsive.
- `app.js` : interactions provisoires.
- `assets/` : dossier réservé aux images et ressources.

## Prévisualiser
Ouvrir `index.html` dans un navigateur. Pour un aperçu local plus fiable, lancer un serveur statique depuis ce dossier, par exemple avec l'extension Live Server de Visual Studio Code.

## Configuration du projet
- Nom : CommerceX
- Devise : HTG (gourdes haïtiennes)
- Paiement prévu : paiement à la livraison
- Hébergement prévu : Netlify
- Données et authentification prévues : Supabase
- Code source : GitHub

## Important
Cette version est une première interface visuelle. Elle ne traite pas encore de commandes et n'est pas connectée à une base de données. Ne collectez pas de vraies données clients avant l'ajout de l'authentification, des règles de sécurité et du backend.
